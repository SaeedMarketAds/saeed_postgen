# Saeed PostGen ⚡
أداة مستقلة لتوليد بطاقات إعلانية احترافية للجوالات والأسعار وتجهيزها للنشر الفوري.

## الميزات
* واجهة بسيطة وسريعة باستخدام Streamlit.
* توليد صور بجودة عالية مناسبة لمنصات التواصل الاجتماعي.
* إمكانية تحميل التصميم مباشرة.
